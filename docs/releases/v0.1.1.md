Table Pro Max 0.1.1 is the first version that can update itself.

It has the same features and look as 0.1.0. The difference is **in-app updates**:
- On first start the app asks once whether it may check for new versions.
- If you agree, it checks once a day and shows a banner when a new version is published.
- One click downloads and installs the update. Every update is verified with the project's signing key before it is installed, and the app asks before it restarts.
- You can change this any time in **Settings › Updates**, or check by hand.

0.1.0 cannot update itself. To get future versions automatically, install 0.1.1 once by hand.

0.1.1 is built from the code just before the design overhaul in progress on `main`. That overhaul arrives in a later version, as an in-app update.

## Please read before installing
- **The installers are not code-signed.**
  - On Windows, SmartScreen asks for confirmation: choose *More info*, then *Run anyway*.
  - On macOS, after copying the app to Applications, run `xattr -dr com.apple.quarantine "/Applications/Table Pro Max.app"` so it opens.

  The in-app updates are signed separately: the app refuses any update the project's key did not sign.
- **Updating by hand from 0.1.0 is safe.** Install 0.1.1 over it. Saved connections, settings and saved passwords are kept.
- **How updates install on Linux:**
  - The AppImage replaces itself. This was tested on a hidden test display.
  - A `.deb` or `.rpm` install is updated through the system package manager after your system password prompt. That path has not yet been run end to end.
- **Not yet tested on real machines:** the update flow on Windows and macOS.

Please report problems.
- **On Linux, saving passwords** needs a Secret Service provider (GNOME Keyring, KWallet with the Secret Service bridge, or KeePassXC). Without one, the app asks for the password each time you connect.
- **Use a least-privilege database role for production.** The safety checks help but are not a guarantee. See [SECURITY_MODEL.md](https://github.com/ayush-eubrics01/table-pro-max/blob/v0.1.1/docs/SECURITY_MODEL.md).
- **macOS Intel builds** are not available yet.
