Table Pro Max 0.9.0 connects to MongoDB, with vector search, and makes restore points cover more.

If you have 0.1.1 or later, the app offers this update itself: a banner appears under the title bar, or go to **Settings › Updates › Check now**.

## New
### MongoDB
- Connect with a `mongodb://` or `mongodb+srv://` address (Atlas), or fill in the form: choose **MongoDB**, then the host, user, auth database, TLS and an SSH tunnel as for the other databases.
- Browse databases and collections. **Find** documents with a filter, sort and projection written as JSON (`{ "status": "paid" }`), page through them, and count them. Results show as a table of fields or as JSON.
- **Aggregate** with a pipeline of reading stages. Pipelines that write (`$out`, `$merge`) are refused.
- **Vector search** (Atlas, or the Atlas local image): pick the vector index and field, paste a query vector, optionally add a filter, and see the closest documents with their scores.
- **Delete** the selected documents, or every document a filter matches. The app counts them first, asks you to confirm that number, and deletes only if the count hasn't changed. Read-only connections can't delete; on production, deleting by filter asks you to type the connection name.

### Restore points
- **Upserts keep restore points.** `INSERT … ON CONFLICT … DO UPDATE`, `ON DUPLICATE KEY UPDATE`, `REPLACE` and `INSERT OR REPLACE` with a `VALUES` list keep the rows they overwrite, so you can put them back. Rows they insert are not removed by a restore, the same as plain INSERTs.
- **SQL files run from disk keep restore points** as a query tab does, and the finish message says how many.
- **Large restores** show a short preview, a progress bar while they run, and **Stop restore**, which rolls everything back.
- **Delete all** of a connection's restore points from its panel. Turning restore points off for a connection offers to delete the ones kept, and **Settings › Safety** shows how much space they use.

### Browsing and editing
- **Rows that point here:** right-click a row to open the rows in other tables that reference it, such as a customer's orders.
- **PostgreSQL enum columns** show their values as tags, and editing offers a list of the allowed values.
- The tab strip works from the keyboard: arrow keys, Home and End move between tabs, and **Delete** closes the focused tab.
- Editing large JSON values stays responsive: values of 100,000 characters or more are checked once you pause typing.
- Copying many long values from query results is faster.
- The restore points panel works better with screen readers: each point's status is read out, deleted rows say so in text, and focus returns where you were.

### Fixed
- Right-clicking a cell outside the selection now acts on that cell. Before, the menu acted on the previous selection, so Copy, Set to NULL and Open referenced row used the wrong cells.
- Clicking inside a cell you are editing no longer saves the edit early.

## Please read before installing
- MongoDB: one host or `mongodb+srv://`; lists of several hosts aren't supported yet. Sign-in is by user name and password. Verified TLS through an SSH tunnel isn't supported; TLS without verification is. MongoDB has no restore points, and inserting or editing documents isn't offered yet.
- MongoDB deletes count the documents just before deleting them. Documents added in between that match the filter are deleted too.
- Untested: MongoDB Atlas itself (only the Atlas local image), and TLS or SSH to MongoDB specifically.
- A large restore still sends one statement per row; it is now visible and can be stopped.
- Installers are not code-signed. On Windows, choose *More info* and then *Run anyway*. On macOS, run `xattr -dr com.apple.quarantine "/Applications/Table Pro Max.app"`. In-app updates are signed separately and verified before they install.
