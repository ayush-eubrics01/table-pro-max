Table Pro Max 0.2.0 has a new look throughout, and fixes a few things that could lose work.

If you have 0.1.1, the app offers this update itself: a banner appears under the title bar, or go to **Settings › Updates › Check now**. From 0.1.0, install 0.2.0 by hand once; later versions then arrive in the app.

## What's new
- **A new design for every screen.** It comes in a dark theme and a light one; System follows your desktop. The Geist fonts and Material Symbols icons ship inside the app, so nothing loads from the internet.
- **Window frame.**
  - On Windows and Linux the app draws its own title bar: connection tabs, search, window buttons. macOS keeps its traffic lights.
  - A coloured stripe under the title bar and the status bar always show which environment you are in. Production stays unmistakable.
- **Connections.**
  - Cards are grouped by environment, production first.
  - Paste a connection URL into the search box to start a new connection from it.
  - A new connection form with engine tiles and environment colours.
  - A "Connecting" dialog that you can hide while the connection carries on.
- **Workspace.**
  - A sidebar with one database/schema switcher and sections with counts.
  - 38 px object tabs.
  - An empty state with New query and Find anything.
- **Tables.**
  - An access pill shows Writable, Insert only or Read-only.
  - Filters show as chips, and pending edits collect in a floating bar.
  - The grid gets foreign-key icons, enum tags and coloured booleans.
  - The row inspector, Structure and Definition (highlighted DDL, Copy SQL, Open in editor) are restyled.
  - The review dialog summarises the statements and highlights the SQL.
- **Queries.** An editor theme built from the app's colours, Run with its shortcut, the target it runs in, Results/Messages/Plan tabs, a History drawer, and the AI panel in the same style.
- **Command palette** (Ctrl+K) with grouped results.
- **Settings** with a section menu: General, Editor, Data grid, Safety, History, **Updates**, **AI assistant**, Shortcuts, About.
- **Keyboard and screen readers.**
  - Arrow keys work in the engine and environment choices.
  - Tabs activate with Enter or Space.
  - Controls are named like their labels.
  - Focus is visible everywhere.

## Fixes
- **Ctrl+W asked nothing before closing a tab.** An unsaved query, or a table with pending row edits, was discarded silently. It now asks, like the tab's × does.
- **A pasted URL the app can't read no longer shows its password** in the connection form.
- **Settings:**
  - Reset to defaults now sticks.
  - A number you typed is saved when you close Settings.
- **Re-clicking the selected database engine**, or arrowing through engines, no longer resets the port or clears the host and SSH tunnel.
- **Tooltips no longer advertise shortcuts that do nothing** (Ctrl+F on the filter button, F5 on reload), and macOS shows ⌘-style shortcuts throughout.

## Please read before installing
- **Installers are not code-signed.**
  - On Windows, SmartScreen asks first: choose *More info*, then *Run anyway*.
  - On macOS, run `xattr -dr com.apple.quarantine "/Applications/Table Pro Max.app"` after copying the app.

  In-app updates are signed separately, and the app refuses any update the project's key did not sign.
- **Not yet checked on real machines:**
  - the new title bar on Windows and macOS (window buttons, macOS traffic-light position);
  - window dragging and resizing on every Linux window manager.

  If the custom title bar misbehaves on your Linux desktop, please report it; native window decorations are the fallback.
- **Updating a `.deb` or `.rpm` install from inside the app** asks for your system password. This is the first release that goes through that path.
- **On Linux, saving passwords** needs a Secret Service provider (GNOME Keyring, KWallet with the Secret Service bridge, or KeePassXC). Without one, the app asks for the password each time you connect.
- **Use a least-privilege database role for production.** See [SECURITY_MODEL.md](https://github.com/ayush-eubrics01/table-pro-max/blob/v0.2.0/docs/SECURITY_MODEL.md).
