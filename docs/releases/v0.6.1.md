Table Pro Max 0.6.1 is a bug-fix release for 0.6.0. It has no new features.

If you have 0.1.1 or later, the app offers this update itself: a banner appears under the title bar, or go to **Settings › Updates › Check now**.

## Fixed
- **JSON keeps columns with the same name apart.** A query such as `SELECT a.id, b.id` now gives `"id"` and `"id_2"` in JSON exports and in Copy rows as JSON. Before, both were written as `"id"` and readers kept only the last one.
- **After a password prompt, the connecting dialog starts its steps and timer again**, instead of counting the time spent typing the password.
- **A connection cancelled before it really started never connects.** Before, it could connect and then be closed straight away.

## Checked
- Rows copied as INSERT statements were run back into the same database on PostgreSQL, MySQL, MariaDB, SQLite and DuckDB, including binary values, quotes, backslashes and NULL. They come back unchanged.

## Please read before installing
- Installers are not code-signed. On Windows, choose *More info* and then *Run anyway*. On macOS, run `xattr -dr com.apple.quarantine "/Applications/Table Pro Max.app"`. In-app updates are signed separately and verified before they install.
