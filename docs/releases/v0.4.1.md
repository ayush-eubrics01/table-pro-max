Table Pro Max 0.4.1 is a bug-fix release for 0.4.0. It has no new features.

If you have 0.1.1 or later, the app offers this update itself: a banner appears under the title bar, or go to **Settings › Updates › Check now**.

## Fixed

### Restore points
- **The restore points list and the count in the status bar stay current.** They refresh after every query run, grid commit and restore, including a COMMIT or ROLLBACK that settles pending points.
- **A grid commit says when it couldn't keep a restore point.** For example: "Committed 1 change. No restore point: changes the primary key".
- **A COMMIT that fails no longer leaves restore points behind** for changes that were rolled back (PostgreSQL and DuckDB).
- **The size limits in Settings › Safety stay consistent.** One restore point can't be set larger than the space for all of them. A restore point that wouldn't fit is not kept, and the app says why.
- **DROP COLUMN:**
  - dropping a primary-key column now asks first, because its rows couldn't be put back by key;
  - the dropped column is matched the way the database matches names.
- **Opening a restore point loads it once**, instead of again every time the panel redraws.

### Editing query results
- **System tables are read-only:** `pg_catalog`, `information_schema`, `mysql.*`, `sqlite_*` and so on. The app also refuses to commit changes to them.
- **`SELECT *, id AS x` stays editable.** A key column shown twice no longer makes the table read-only.
- **Clearer reasons:**
  - when the server doesn't report where columns come from (as behind a connection pooler), the app says so, instead of calling every column "Computed column";
  - materialized views and foreign tables are named correctly;
  - rows keyed by a binary value say why they can't be edited.
- **Edits waiting in another result tab are shown.** The tab has a dot, and the pending-changes bar says "N pending changes in another result", with **Show**.

### Data grid
- **A click right after a table or result appears is no longer lost.** The grid could clear its selection just after showing, undoing a quick click: copy, export and Ctrl+Enter then acted on nothing.

## Please read before installing
- Installers are not code-signed. On Windows, choose *More info* and then *Run anyway*. On macOS, run `xattr -dr com.apple.quarantine "/Applications/Table Pro Max.app"`. In-app updates are signed separately and verified before they install.
