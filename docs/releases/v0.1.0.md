First public preview of Table Pro Max: a free, privacy-first desktop database client for
PostgreSQL, MySQL, MariaDB, SQLite, DuckDB and Redis.

Everything is free. There is no account, no license key, no telemetry and no usage limits.

## What's in it
- **Connections:** saved profiles with groups and environments (production is styled distinctly),
  URL import, SSH tunnels with host-key checks, TLS options. Passwords are kept in the OS
  credential store or asked for every time, never in the app's own files.
- **SQL editor:** a tab per session, autocomplete for tables and columns, formatting, run the
  current statement, the selection or everything, cancel, timeouts, history and saved queries,
  EXPLAIN view.
- **Data browser:** a fast virtualized grid, filters, sorting, and inline edits. Edits stay
  pending until you review the generated SQL and commit them in one transaction.
- **Safety:** destructive statements ask first, and read-only connections are enforced by the
  database session itself.
- **Schema:** structure view and DDL. Create or alter tables and indexes, with every change
  previewed as SQL first.
- **Import and export:** export results or whole tables to CSV, JSON, JSON Lines, SQL INSERT
  statements or Excel. Import CSV, TSV, JSON or JSON Lines into an existing or new table, in one
  transaction.
- **Dashboards:** charts built from SQL widgets.
- **Redis:** browse keys, view and edit values, and use a command console.
- **AI assistant (optional, off by default):** explain or improve a query, fix an error, or
  write SQL from a description. It works with Anthropic or any OpenAI-compatible server,
  including local ones. Every request is shown before it is sent. Suggested SQL is only ever
  inserted into the editor, never run.

What each feature does, and how it was tested, is in
[FEATURE_MATRIX.md](https://github.com/ayush-eubrics01/table-pro-max/blob/v0.1.0/docs/FEATURE_MATRIX.md).

## Please read before installing
- **The installers are not code-signed.** On Windows, SmartScreen asks for confirmation:
  choose *More info*, then *Run anyway*. On macOS, after copying the app to Applications, run
  `xattr -dr com.apple.quarantine "/Applications/Table Pro Max.app"` so it opens.
- **This is a preview.** The Linux build has been run and tested. The Windows and macOS
  installers are built and checked in CI, but nobody has launched them on a real machine yet.
  Please report problems.
- **On Linux, saving passwords** needs a Secret Service provider (GNOME Keyring, KWallet with
  the Secret Service bridge, or KeePassXC). Without one, the app asks for the password each time
  you connect.
- **Use a least-privilege database role for production.** The safety checks help but are not a
  guarantee. See
  [SECURITY_MODEL.md](https://github.com/ayush-eubrics01/table-pro-max/blob/v0.1.0/docs/SECURITY_MODEL.md).
- **macOS Intel builds** are not available yet.
