Table Pro Max 0.8.0 connects to Microsoft SQL Server.

If you have 0.1.1 or later, the app offers this update itself: a banner appears under the title bar, or go to **Settings › Updates › Check now**.

## New
### SQL Server
- Connect with a SQL Server login: choose **SQL Server** in the connection form (port 1433), paste a `sqlserver://` URL, or paste a connection string from the Azure portal or SQL Server tools (`Server=tcp:host,1433;Database=…;User ID=…;Password=…`). TLS, a CA certificate and SSH tunnels work as for the other databases.
- Browse databases, schemas (`dbo` first), tables, views, procedures, functions and sequences, with their columns, keys, indexes, constraints and triggers.
- Scripts run in batches separated by `GO`, as in SQL Server Management Studio, so variables, `IF … BEGIN … END` blocks and procedure bodies work. **Ctrl+Enter** runs the statement at the cursor; **Run all** runs every batch.
- Edit rows in tables and query results, filter and sort, page through large tables, use query parameters, import and export, and keep restore points (identity values come back as they were).
- Values show as SQL Server Management Studio shows them: dates and times with their digits, money with four decimals, GUIDs in capitals.
- Safety works as for the other databases: destructive statements ask first (including inside `IF` blocks and `MERGE … DELETE`), and read-only connections roll back every batch and refuse `COMMIT`.

### Fixed for every database
- **Cancel stops the query you meant.** When two runs share a tab's connection, cancelling one no longer stops the other, and a cancel that arrives just after a query finished no longer interrupts anything.

## Please read before installing
- **Cancelling a SQL Server query reopens its connection.** This includes a query timeout. Temporary tables, variables, SET options and any open transaction are lost, and the message says so. This comes from a bug in the SQL Server driver the app uses; it goes away once the driver is fixed.
- Not yet on SQL Server: query plans (Explain is hidden), Windows and Microsoft Entra sign-in, and named instances (use the instance's port). Tested with SQL Server 2022; Azure SQL is untested.
- Installers are not code-signed. On Windows, choose *More info* and then *Run anyway*. On macOS, run `xattr -dr com.apple.quarantine "/Applications/Table Pro Max.app"`. In-app updates are signed separately and verified before they install.
