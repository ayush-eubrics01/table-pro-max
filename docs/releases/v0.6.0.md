Table Pro Max 0.6.0 shows what a connection is doing while it opens, lets you stop it, and copies rows as JSON or INSERT statements.

If you have 0.1.1 or later, the app offers this update itself: a banner appears under the title bar, or go to **Settings › Updates › Check now**.

## New
### See and stop a connection while it opens
- The connecting dialog lists the steps: opening the SSH tunnel (when there is one), connecting and signing in, reading server info, and loading schemas. It also shows how long it has taken.
- **Cancel** (or Escape) stops the attempt straight away, without an error and without waiting for the timeout.
- **Hide** still lets the connection carry on in the background.
- Redis connections show the dialog as before, without steps or Cancel.

### Copy rows as JSON or INSERT statements
- Right-click rows in a table or a query result and choose **Copy rows as JSON** or **Copy rows as INSERT**.
- INSERT statements are written for your database, one per row, into the table the rows come from, using that table's column names. Rows that don't come from a single table go into `query_result`.
- Up to 100,000 rows at a time; export larger sets.
- Values are quoted exactly as in an export. Values not loaded yet are read in full first.

## Fixed
- **A server that accepts the connection but never answers no longer leaves the app waiting forever.** Connecting to a server now stops after the connection's timeout (Safety & timeouts, 10 seconds by default) with "The server did not answer within 10s". Local SQLite and DuckDB files have no time limit.
- **JSON exports keep the column order.** Keys were written in alphabetical order.

## Please read before installing
- Installers are not code-signed. On Windows, choose *More info* and then *Run anyway*. On macOS, run `xattr -dr com.apple.quarantine "/Applications/Table Pro Max.app"`. In-app updates are signed separately and verified before they install.
