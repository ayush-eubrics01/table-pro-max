# Jump to Referenced Row Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A foreign-key cell (in an opened table or a query result traced to a foreign-key column) gets a corner arrow, **Ctrl/⌘+Enter** and a context-menu item that open the referenced table in a new tab, filtered to that row.

**Architecture:**
- **Link computation.** A pure module (`fkLinks.ts`) works out, per grid column, which foreign keys a column belongs to, and builds the target filter from a row's values.
- **Grid.** It renders the arrow from a `cellLink` callback.
- **Opening the tab.** The workspace store opens a filtered table tab, always new. The filter is persisted with the session, and TableView starts from it.
- **Backend.** No backend change: the target tab uses the existing filtered `browse`.

**Tech Stack:** React/TypeScript, zustand, Vitest. No Rust changes.

**Spec:** `docs/superpowers/specs/2026-10-14-fk-jump-design.md`

## Global Constraints
- **No new SQL and no new backend command.** Filters go through the existing `browse` and filter compiler.
- **New tab every time** for a followed reference. A plain open (sidebar, palette) never lands on a filtered tab.
- **No arrow** when any value of the foreign key in that row is NULL, Not loaded (`{ $notLoaded: true }`), a preview (`{ $partial }`) or binary. Also none on new unsaved rows.
- **Exact copy:**
  - tooltip and `aria-label` `Open <refTable> where <col> = <value>`, joined with ` and ` for composite keys;
  - context menu `Open referenced row`, or `Open referenced row in <refTable>` when the column is in more than one foreign key.
- **Arrow icon:** `open_in_new`, size 12. CSS shows it only on `.grid-cell:hover` or `.grid-cell.active`.
- **Node:** `source ~/.nvm/nvm.sh && nvm use 24`. Don't run prettier on whole files.

## Review Focus
1. **A query result with the same foreign-key column twice** (a self-join: `e.manager_id`, `m.manager_id`). For a single-column key, each column links with its own value. A composite key whose columns are ambiguous gets no link. Tested in Task 1.
2. **A composite foreign key with one NULL part.** No arrow on any of its columns. Tested in Task 1.
3. **Clicking the arrow** never opens the inline editor or triggers a double-click edit. Tested in Task 2.
4. **A restored session** reopens a followed-reference tab still filtered. Tested in Task 3.
5. **A foreign-key cell with a pending edit.** The jump uses the value shown in the grid (the edited one). Tested in Task 4.

```ts
// Following a foreign key: which grid cells link to a referenced row, and the filter that finds
// it. A foreign key references a primary or unique key, so the filter matches at most one row.

import type { Cell, ColumnMeta, ForeignKeyInfo, TableStructure } from "../../types/backend";
import { cellParam, isNotLoaded, isPartial } from "../../lib/cells";
import type { GroupNode } from "../filters/filterModel";

export interface FkLink {
  fk: ForeignKeyInfo;
  /** Grid column index for each of `fk.columns`, in order. */
  columns: number[];
}

function add(byCol: FkLink[][], link: FkLink) {
  for (const i of link.columns) byCol[i]!.push(link);
}

export function tableLinks(s: TableStructure): FkLink[][] {
  const byCol: FkLink[][] = s.columns.map(() => []);
  for (const fk of s.foreignKeys) {
    const columns = fk.columns.map((n) => s.columns.findIndex((c) => c.name === n));
    if (columns.every((i) => i >= 0)) add(byCol, { fk, columns });
  }
  return byCol;
}

export function resultLinks(columns: ColumnMeta[], structures: TableStructure[]): FkLink[][] {
  const byCol: FkLink[][] = columns.map(() => []);
  for (const s of structures) {
    const from = (name: string) =>
      columns.flatMap((c, i) => (c.origin && c.origin.schema === s.schema && c.origin.table === s.name && c.origin.column === name ? [i] : []));
    for (const fk of s.foreignKeys) {
      if (fk.columns.length === 1) {
        // Each result column traced to the key column links with its own value.
        for (const i of from(fk.columns[0]!)) add(byCol, { fk, columns: [i] });
        continue;
      }
      // A composite key needs each part exactly once; otherwise the parts can't be paired up.
      const parts = fk.columns.map((n) => from(n));
      if (parts.every((p) => p.length === 1)) add(byCol, { fk, columns: parts.map((p) => p[0]!) });
    }
  }
  return byCol;
}

function linkValues(link: FkLink, row: Cell[]): string[] | null {
  const out: string[] = [];
  for (const i of link.columns) {
    const c = row[i];
    if (c === undefined || c === null || isNotLoaded(c) || isPartial(c)) return null;
    const v = cellParam(c);
    if (v === undefined || v === null) return null;
    out.push(v);
  }
  return out;
}

export function linkFilter(link: FkLink, row: Cell[]): GroupNode | null {
  const values = linkValues(link, row);
  if (!values) return null;
  return {
    type: "group",
    logic: "and",
    children: link.fk.refColumns.map((column, k) => ({ type: "condition", column, op: "eq", value: values[k]!, enabled: true })),
  };
}

export function linkLabel(link: FkLink, row: Cell[]): string | null {
  const values = linkValues(link, row);
  if (!values) return null;
  return `Open ${link.fk.refTable} where ${link.fk.refColumns.map((c, k) => `${c} = ${values[k]}`).join(" and ")}`;
}
```
